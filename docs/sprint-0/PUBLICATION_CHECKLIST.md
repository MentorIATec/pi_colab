# Lista mínima para publicación

Esta lista aplica al sitio y a los nuevos formatos creados para el taller. No se
publicarán copias de reglamentos, presentaciones internas, capturas de MiTec ni
otros materiales institucionales preexistentes.

## Antes de construir la versión pública

- [ ] Programas Internacionales confirma que el alcance y las instrucciones de
  los formatos son correctos.
- [x] Se confirma que PI mantiene fechas, oferta, costos y requisitos solamente
  en MiTec; el proyecto no duplica ese repositorio.
- [ ] Se identifica a la persona de PI que dará visto bueno al contenido y
  notificará cambios que afecten las rutas de atención.
- [x] Se decide presentar el recurso con una identidad neutral de colaboración,
  sin aparentar ser un canal oficial alterno a MiTec.
- [ ] Se confirma quién tiene la titularidad de los nuevos materiales y quién
  puede autorizar su publicación.
- [ ] No se asigna una licencia personal, incluida Creative Commons, mientras la
  titularidad institucional no esté aclarada.
- [x] Se excluyen logotipo, escudo, tipografías propietarias y reproducción de la
  identidad oficial mientras no exista una autorización específica.

## Contenido y fuentes

- [x] Los documentos institucionales se citan o enlazan; no se reproducen.
- [x] Mi Experiencia Internacional en MiTec aparece como fuente primaria.
- [ ] Cada dato variable tiene responsable, fecha de actualización o enlace a la
  fuente vigente.
- [ ] Cuando MiTec no contiene una respuesta, el formato indica el canal de PI o
  una instrucción de investigación autónoma con fuente y fecha.
- [ ] El sitio incluye una nota visible de que convenios, costos, requisitos,
  cursos y fechas deben verificarse antes de tomar una decisión.

## Datos y privacidad

- [x] Los formatos no solicitan matrícula, pasaporte, visa, expedientes, datos
  financieros, información de salud ni otra información sensible.
- [ ] Si existe guardado local, se explica qué se guarda, cómo borrarlo y el
  riesgo de usar un dispositivo compartido.
- [ ] No se incorporan analítica, formularios externos o envío de información sin
  una revisión específica de privacidad.

## Calidad y operación

- [ ] La experiencia cumple criterios básicos de accesibilidad WCAG AA y funciona
  con teclado y dispositivos móviles.
- [ ] Se prueba la navegación con enlaces que requieren autenticación en MiTec.
- [ ] Se define repositorio, URL, responsable técnico y procedimiento de
  actualización o retiro.
- [ ] La versión aprobada y su fecha quedan registradas antes de publicarse.

## Decisión de alcance

Esta lista no exige obtener una licencia para copiar las presentaciones fuente,
porque no serán incorporadas al sitio. Se propone titularidad institucional para
los formatos nuevos, con reconocimiento explícito de concepto, diseño,
facilitación y validación. El texto final requiere visto bueno antes de publicar.
