# Sprint 1 — Diseño de la experiencia

**Estado:** En curso  
**Inicio:** 5 de agosto de 2026

## Objetivo

Convertir las decisiones del Sprint 0 en una experiencia facilitada que pueda
revisarse con Programas Internacionales antes de construir el sitio o convocar
estudiantes.

La ruta incorporó posteriormente una microintervención independiente de 30
minutos para grupos pequeños. Esta variante preserva los límites institucionales,
pero permite probar desde mentoría la claridad del encuadre y de las herramientas
de decisión sin impartir contenido oficial de PI.

## Hipótesis de experiencia

Una sesión enfocada en propósito, filtros, criterios y ruta de acompañamiento
permitirá que un estudiante que comienza desde cero continúe investigando sin
confundir estimaciones con información institucional confirmada.

## Entregables

- [x] Agenda base de 90 minutos.
- [x] Variante de 60 minutos.
- [x] Microintervención de 30 minutos para 3 a 5 estudiantes.
- [x] Actividad previa de 10 a 15 minutos.
- [x] Guía de exploración en baja fidelidad.
- [x] Caso ficticio para practicar filtros y comparación.
- [x] Guía inicial de facilitación.
- [x] Plan de evaluación sin seguimiento obligatorio.
- [ ] Revisión de escritorio con Programas Internacionales.
- [ ] Revisión de escritorio con mentoría y representación académica.
- [ ] Ajustes derivados de ambas revisiones.

## Gate institucional

Los materiales de este sprint son prototipos. No deben utilizarse con estudiantes
ni comunicarse como información oficial hasta que PI valide vocabulario, rutas,
enlaces y límites.

## Criterios de salida

- El recorrido cabe en el tiempo incluyendo transiciones y margen.
- Cada bloque produce una sección concreta de la Guía de exploración.
- Las modalidades de 60 y 90 minutos comparten los mismos resultados mínimos;
  la variante de 30 minutos utiliza una Guía de exploración y delega la lista de
  siete opciones al trabajo autónomo.
- El caso no utiliza instituciones, convenios o costos reales.
- PI puede identificar claramente qué contenido debe validar.
- La evaluación no recopila datos personales ni obliga seguimiento posterior.
